# Hero Movie Invite (Streamlit)

A superhero-inspired, comic-style Streamlit web app with original artwork and interactions.

## Features

- Red/blue/black comic-book visual theme
- Original spider webs, sparkles, skyline silhouettes, and swinging spider animation
- Typewriter message animation
- Runaway `No` button with playful retry messages
- Celebration state on `Yes` with confetti, flying webs, and floating hearts
- Optional ambient sound that starts only after user click
- Mobile-friendly responsive layout

## Local Run

1. Install dependencies:
   - `pip install -r requirements.txt`
2. Start app:
   - `streamlit run app.py`

## Deploy on Streamlit Community Cloud

1. Push this folder to a GitHub repository.
2. Go to Streamlit Community Cloud.
3. Click **New app**.
4. Select your repository and branch.
5. Set main file path to `app.py`.
6. Deploy.

The app should run without extra configuration.

## Copyright Safety

This project intentionally uses only original superhero-inspired graphics and CSS/SVG effects.
It does not include Spider-Man logos, movie posters, Marvel assets, or copyrighted artwork.
